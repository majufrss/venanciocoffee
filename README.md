# Venâncio Coffee ☕
Landing page da marca Venâncio Coffee — um projeto de identidade e desenvolvimento web.

## Sobre o projeto
O Venâncio Coffee nasceu de uma linda homenagem ao meu avô. Ele era um homem bom, que tinha uma paixão genuína por café. Movidas pelo desejo de espalhar esse amor e esse sabor para o mundo, minha mãe, minha irmã e eu nos unimos para dar vida ao Venâncio Coffee.

## Tecnologias
- HTML5
- CSS3 responsivo
- JavaScript puro

## Como visualizar
Abra o arquivo `index.html` no navegador ou publique o repositório com o GitHub Pages.
