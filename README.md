# Venâncio Coffee ☕
Landing page da marca Venâncio Coffee — um projeto de identidade e desenvolvimento web.

## Sobre o projeto
Uma página de apresentação inspirada na história da família Venâncio, com uma estética acolhedora, editorial e vintage. O conceito celebra o café como parte dos pequenos rituais do dia a dia.

## Tecnologias
- HTML5
- CSS3 responsivo
- JavaScript puro

## Como visualizar
Abra o arquivo `index.html` no navegador ou publique o repositório com o GitHub Pages.
